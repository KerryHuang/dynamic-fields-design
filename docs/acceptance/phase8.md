## 已知限制

- 範本只帶群組層的權限建議，不帶欄位隱藏、唯讀、選項範圍、個人權限；套用後要到權限分頁補（spec §15 第 47 條）。
- 匯入的範本不能刪除、覆蓋；同代碼再匯入回 409（spec §15 第 48 條）。
- 範本沒有版本升級：已經從範本建出的模組，不會因為範本改了而更新（spec §15 第 49 條）。
- 匯出時無法表達的引用直接省略，只在檔案的 `warnings` 說明（spec §15 第 50 條、裁決 R7、R8）。
- 結構驗證不檢查型別設定，匯入的範本要到套用時才會發現這類錯誤（spec §15 第 51 條）。
- 「預設今天」在前端用瀏覽器本地日期、後端用營運時區（spec §15 第 52 條，同第 26 條）。
- 「帶表頭的值」只在新增明細列時帶值，之後改表頭不會更新明細（spec §15 第 53 條）。
- 從範本建立是重播設計器指令，訂單範本約 60 次指令，新模組的版本號一開始就大於 1（spec §15 第 54 條）。
- 「帶表頭的值」可能把呼叫端看不到的表頭值帶進新的明細列，只有直接呼叫 API 又省略該鍵時才會發生（spec §15 第 55 條）。
- 內建範本由 Application 層直接讀檔案系統載入，上線時要移到 Infrastructure（spec §15 第 56 條）。
