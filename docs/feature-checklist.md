## 決定不做

共 19 項。

- [-] 計薪公式、折舊攤提、缺料計算（MRP）、自動排程 — 計算類
- [-] 外掛與腳本執行環境 — 只在事件設計中留接口
- [-] 多公司、多租戶 — 不追 Odoo 的模組數量
- [-] 職務分離 — 平台類
- [-] 對外 API 與 Webhook、全站搜尋 — 平台類
- [-] 多幣別、單位換算、版本與有效日期 — 資料類
- [-] 同畫面編輯三層明細 — 明細維持一層
- [-] 應用程式升級合併 — 開啟後屬於客戶，新版不自動合併
- [-] 申報檔、電子發票串接、內建法定費率 — 法規類
- [-] 甘特圖 — 呈現類
- [-] AD／SSO／雙因素、自助註冊、寄信重設密碼 — 使用者管理非目標
- [-] 客戶自訂主題顏色、字型、Logo — 只在四種風格與三種模式間選
- [-] 垃圾桶還原、批次刪除、一鍵清空 — 安全刪除不在範圍
- [-] 報表排程寄送、拖拉式 BI、使用者自寫 SQL — 報表非目標
- [-] 逐列轉換（一列轉一張單據） — 第二個情境未出現，不排
- [-] 預留、訂單專屬庫存、出貨單自動產生、超交容許量、存貨計價 — s2e 不做
- [-] 任務的子任務、相依、優先度、重複任務、工時、Email 與推播 — 任務第一版不做
- [-] 倉庫共用主檔 — 只有進銷存用，不符兩個不相干應用程式的門檻
- [-] 簽核並行分支、抄送、批次同意、Email 通知 — 簽核第一版不做，列第二版候選
