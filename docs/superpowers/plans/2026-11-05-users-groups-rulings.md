# 使用者與群組實作裁決

執行 [`2026-11-05-users-groups.md`](2026-11-05-users-groups.md) 時，對計畫與設計文件的補充與修正。與計畫衝突時以這裡為準；第 1–8 階段與 Demo 資料的裁決仍然有效。設計文件在[這裡](../specs/2026-11-05-users-groups-design.md)，操作說明在[操作手冊](../../manual.md)與 [Demo 腳本](../../demo.md)。

格式：裁決 — 理由 — 錯了的代價。

## 開工前檢查

- Demo 模式下，`admin` 的引導不要求改密碼。這偏離設計文件 §7 的字面（引導一律要求改密碼），但符合 §8「一鍵登入不要求改密碼、也不寫資料庫」。理由：否則第一位訪客一鍵登入就得寫資料庫，會卡在 Demo 產生器持有的寫入鎖。錯了的代價：Demo 站上用密碼登入 `admin` 時不會被要求改密碼，只影響 Demo 站。
- 任務 2 可以修改 `ServiceResult.cs` 與 `ToActionResult`，加入 `Unauthorized`，雖然計畫的檔案清單沒列。理由：計畫的介面已經明定這個方法。錯了的代價：多一個小改動。

## 任務 1：資料模型與示範人員

- `DemoGeneratedFixture` 只跑核心種子，視為已驗證，不補示範人員。理由：補了之後，產生器測試會因為示範人員已存在而衝突失敗，而實作者回報的測試是全綠的。錯了的代價：測試本身會變紅，不影響正式行為。

## 任務 2：驗證機制

- 正式程式不快取 `SecurityStamp` 與 `IsActive`。`WhileGenerating` 測試若遇到 in-memory shared-cache 的「table is locked」，改用暫存檔資料庫跑。理由：設計文件要求停用要立即生效，快取會讓失效延遲；檔案模式才是正式部署的行為。錯了的代價：測試稍慢。
- 鎖定的競態用程序內的分段鎖處理：固定 64 個 `SemaphoreSlim`，依帳號雜湊挑一個，讓同一帳號的登入嘗試排隊，不採「寫入前先遞增計數」。理由：每家客戶單一 instance，這樣就夠；成功登入維持不寫資料庫，不會卡在 Demo 產生器的寫入鎖。錯了的代價：日後若改成多個 instance 並行，要換成資料庫層的原子更新。
- 新增啟動救援設定 `Auth__ResetAdminPassword`：啟動時若有設定，重設 `admin` 的密碼、啟用、解鎖、要求改密碼、換掉 `SecurityStamp`，並寫一筆 Warning，文件要求用完就移除。理由：設計文件的反目標是「管理員把自己鎖在外面只能改資料庫」，而唯一的管理員忘記密碼時，原本真的只能改資料庫。錯了的代價：多一個需要主機權限才能使用的開關。
- Swagger 只在 Development 環境開放。理由：設計文件 §4 的匿名清單沒有它，正式站不該公開 API 文件。錯了的代價：Render 上看不到 Swagger。
- Render 的 `Auth__TrustForwardedHeaders` 由任務 3 加上。任務 2 的審查者提出疑慮，確認計畫任務 3 步驟 3 已明列。理由：計畫已涵蓋。錯了的代價：Render 上的 cookie 不會有 `Secure`；任務 9 的走查不含 Render，這點列為未驗證。

## 任務 4：使用者管理 API

- 直接呼叫 API 仍可把記錄指派給已停用的使用者，不擋。理由：設計文件要的是舊記錄不壞、畫面不再列出停用者；存檔時要區分新值與舊值，成本高，而且畫面上走不到這條路。錯了的代價：只有手動呼叫 API 的人能把記錄指派給離職者。

## 任務 5：群組管理 API

- 實作者的 commit（e88c2dc）署名寫 Sonnet 5.5，與約定的 Opus 5.5 不同，不 amend。理由：實際執行的就是 Sonnet，內容不影響功能，改寫歷史沒有必要。錯了的代價：一行署名不一致。

## 任務 6：前端登入

- `GET /me` 失敗且不是 401 時，導到公開頁面（文字「目前無法連線到伺服器，請稍後再試」），附「重試」按鈕（重新載入原路徑），不清除 session。理由：帶著有效 cookie 的人不該因為伺服器暫時故障被要求重打密碼，也不能讓畫面留白。錯了的代價：多一個小頁面與四語系文字。

## 任務 9：收尾審查

- 成功登入後把失敗次數歸零的缺陷，直接修程式並補測試，不改文件遷就。理由：設計文件 §4 明訂成功登入後歸零，`LoginHandler` 只 commit 沒歸零，是任務 2 漏的。錯了的代價：一行程式與一個測試。
- 文件引用的畫面文字，改成實際的 i18n 字串（例如「目前無法連線到伺服器，請稍後再試」），不動 UI 文案。理由：文案已翻成四語，改文件範圍最小。錯了的代價：之後想改文案時，文件要一起改。
