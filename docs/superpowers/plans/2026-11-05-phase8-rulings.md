# 第 8 階段實作裁決（R1–R13）

執行 [`2026-11-05-phase8-templates.md`](2026-11-05-phase8-templates.md) 時，對計畫原文的補充與修正。格式：裁決 — 理由 — 錯了的代價。與計畫衝突時以這裡為準；第 1–7 階段的裁決仍然有效。

- Ruling R1: 測試專用的範本由 WebAPI 測試主機替換 `TemplateCatalog`／`ITemplateSource` 注入，不放進 `poc/backend/templates` — 內建範本目錄只放真的要給客戶的範本 — 錯了的代價：調整測試主機。
- Ruling R2: 「帶表頭的值」與預設值或預設今天同時設定時回 400，鍵 `Config.ParentDefaultFieldId`，訊息 `帶表頭的值不能同時設定預設值或預設今天` — 計畫說三者互斥，但沒給訊息 — 錯了的代價：一個字串。
- Ruling R3: 鎖定欄位＝每個模組的標題欄位加上所有明細參照欄位；欄位的依賴包含公式引用、彙總的來源欄位、彙總欄位與條件欄位，以及「帶表頭欄位」 — 決策 3、5 有暗示但沒列明 — 錯了的代價：調整依賴圖。
- Ruling R4: 區塊、欄位代號放寬為 `^[a-z][a-zA-Z0-9_]{0,39}$`（允許 camelCase） — 決策 1 的規則和決策 9 用的代號（`orderDate` 等）衝突；代號不會變成 `Field.Key`，`Field.Key` 仍是 `f_<Id>` — 錯了的代價：改一個 regex。
- Ruling R5: 套用範本的第 9 步不送 `CreateView`，而是先跑 `CreateViewValidator` 與 `ViewRules.Check`，再直接寫入共用檢視 — `CreateView` 不接受草稿模組（計畫缺陷）；驗證相同，也不必改既有指令 — 錯了的代價：檢視不經過 `CreateView` 的設計器 Edit 權限檢查（套用本身已要求設計器 Add）。
- Ruling R6: 自訂訊息 `範本沒有欄位「m.f」`、`範本沒有模組「x」`；規則沒有條件時送 `{"all":[]}`；沒有規則就不送 `SaveRules`；範本裡的群組在目標庫一個都不存在時，不送 `SaveModulePermissions` — 計畫沒寫 — 錯了的代價：幾個字串。
- Ruling R7: 匯出時，「帶表頭欄位」指向範本外的欄位，只拿掉這個設定並加一則警告，欄位本身照常匯出；這條推翻決策 6 的「整個欄位不匯出」 — 否則單獨匯出明細模組時，「交期」欄位會整個消失 — 錯了的代價：一個分支。
- Ruling R8: 匯出時：
  - 引用停用選項的規則不匯出，並加一則警告。
  - 全部動作都是 false、又沒有資料範圍的群組權限不匯出。
  - `isEmpty` 只在範本 JSON 裡拿掉。
  - handler 匯出時不跑結構驗證（測試會跑）。
  - 錯了的代價：小。
- Ruling R9: 「從範本建立」對話框的模組代碼可以編輯 — brief 的模組卡片列了「代碼」；遇到 409 時使用者可以直接改 — 錯了的代價：拿掉一個輸入框。
- Ruling R10: 內建訂單範本的權限建議：業務有金額軸（資料範圍本人），沒有金額軸的示範改用「現場人員」群組（只有讀取、資料範圍全部） — spec §13.1 把「業務」與「看不到單價與金額的群組」列為兩條；計畫決策 9 把兩者混為一談，導致業務建的訂單合計都是 0 — 錯了的代價：改範本 JSON 的權限三行。
- Ruling R11: 範本裡 `formula`、`rollup` 只在公式、彙總欄位才算引用；其他型別的設定帶了 `formula` 或 `rollup`，結構驗證直接擋下（「{模組}.{欄位}: 只有公式欄位可以設定公式」「…: 只有彙總欄位可以設定彙總」）。公式的 `{代號}` 與 `opt_<代號>` 的判斷只寫在 `TemplateGraph` 一處，驗證、依賴圖與套用共用 — 原本套用時對任何型別都替換 `formula`、轉換 `rollup`，驗證卻只看公式、彙總欄位，匯入的範本可能通過驗證後在套用時 500 — 錯了的代價：兩條驗證訊息與一個共用定義。
- Ruling R12: 檢視回應裡，讀者看不到的欄位（例如沒有金額軸時的金額欄）從欄、排序、篩選靜靜剔除，不列入 `staleFieldIds`；`staleFieldIds` 只列已停用、或不再開放篩選、排序的欄位 — 否則列表會顯示「此檢視有 1 個欄位已停用或不再開放篩選、排序，已略過」，但欄位其實沒停用 — 錯了的代價：一個判斷式。
- Ruling R13: 模組清單的「從範本建立」要設計器同時有新增與修改權限才顯示；「匯入範本」仍只需新增 — 套用範本會重播區塊、欄位、規則等修改指令，只有新增權限的人按了一定 403 — 錯了的代價：一個 `v-if`。
